# Kamama Clinic Card

אפליקציית כרטיסיות טיפולים דיגיטלית עם:
- כניסת מנהל
- צפיית לקוח לפי קישור סודי `/card/<token>`
- חיבור ל-Supabase

## העלאה ל-Vercel
1. העלה את הפרויקט ל-GitHub או גרור את התיקייה/ZIP ל-Vercel אם האפשרות קיימת.
2. Framework: Vite
3. Build command: `npm run build`
4. Output directory: `dist`
